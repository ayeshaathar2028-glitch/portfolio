# Aisha Athar — Digital Marketing Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content, SEO metadata, and Person structured data
- `style.css` — responsive visual design
- `script.js` — mobile navigation, service preselection, current year, and email inquiry form
- `assets/` — folder reserved for your real photos, logo, and project screenshots

## Run locally
Open `index.html` in a browser. For a local server, use VS Code's Live Server extension.

## Before publishing
1. In `script.js`, replace `YOUR_EMAIL@example.com` with your real professional email address.
2. Add your real profile photo, contact details, and professional social links if desired.
3. Replace practice-project visuals and descriptions with genuine project samples. The existing portfolio examples are explicitly labelled practice projects.
4. Confirm the canonical domain and update the structured data URL when you choose your final domain.
5. If you want the contact form to submit without opening the visitor's email app, connect a form backend/service and update the form handler.
6. Add a privacy policy that reflects the actual data collection and analytics you use.
7. Test links, form behavior, mobile layout, accessibility, and SEO metadata before launch.
8. Add your deployed site to Google Search Console and submit the sitemap when available.
